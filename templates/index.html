Customer Churn Prediction

Harnessing the power of machine learning to predict customer churn risk with precision and actionable insights.

Project Overview

This project showcases a real-world machine learning application predicting customer churn based on demographic, transactional, and engagement data. The workflow covers the full ML lifecycle from data exploration to deployment.

The Data

  • Demographics: age, gender, region
  • Membership: category, joining date
  • Engagement: last login, avg. time spent, transaction value
  • Feedback: complaints, feedback

Target: churn_risk_score — numerical probability of churn.

Data Preprocessing

  • Handled missing values via mean/mode imputation
  • Engineered features like join date split into day, month, year
  • One-hot encoded categorical features
  • Removed outliers to improve training stability

Exploratory Data Analysis

EDA included rich visualizations to reveal trends and relationships.

Modeling

  • Decision Tree
  • Random Forest ✅ (Best Performer)
  • Artificial Neural Network (ANN)
